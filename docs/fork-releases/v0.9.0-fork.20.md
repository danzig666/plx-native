# v0.9.0-fork.20 — Skip intros / Skip credits for every profile, numbered 0.9.20
PlxNative from upstream's main branch as of 2026-11-05 (everything in [upstream v0.9.0](https://github.com/GLinnik21/plx-native/releases/tag/v0.9.0)) plus this fork's changes, built from [`claude/plx-native-version-diff-9faa0w`](https://github.com/danzig666/plx-native/tree/claude/plx-native-version-diff-9faa0w) by the fork's Sideload build workflow.

## New in this build

- **Skip intros and Skip credits are in Settings > Playback for every profile.** Upstream shows them only when plex.tv says the profile's own account has the intro and credits marker features, which hid them here. The fork shows them for any signed-in profile; the skipping uses the markers your server provides. Manual (the skip button, as before), Disabled or Automatic (a five-second countdown, then the skip), per profile.
- The events log now says what plex.tv answered about those features (`marker grants:`), in case it is ever needed.

## From fork.19


**Upstream main of 2026-11-05** merged in (97 changes since fork.18), among them:

- **The player's controls are rebuilt** as installable HUD packages; the built-in look is one of them, and the player's menus open beside the button that opened them.
- **Automatic intro and credits skipping** (Settings > Playback, per profile: Manual, Disabled or Automatic; Plex Pass). This replaces the fork's own Skip intros / Skip credits settings, so that choice is asked again.
- **A Dolby Vision Auto/Off setting** per profile.
- **BACK closes a Skip or Up Next offer** and brings the player's buttons back.
- **Libraries:** the A-Z rail also groups other sorts (rating, length, date added, date watched, release year) and works for a TV library's Seasons and Episodes; the sort value can show under the posters; a sort control in the header; a visited library stays loaded.
- **Moving on to the next episode marks the finished one watched.**
- Detail: a Go to Show button on an episode; Change profile opens on the profile that is watching; smoother BACK onto a library and from a cast page; posters stop blinking.
- MPEG-TS files named `.mp4` play directly; an external subtitle over a remux keeps time.
- Dutch, Arabic and Hebrew translations.
- Both of this fork's upstream pull requests are in: Magic Remote edge scrolling (#986) and seeking in Blu-ray remuxes (#1085).

This fork's own changes on top:

- **Partly visible posters on Home take the Magic Remote pointer**, as they do in the libraries: hovering one highlights it, including the shelf peeking under the big picture.
- From fork.18: a click opens a poster where it is (the page does not scroll to it first), and the top of Home glides at normal speed.
- The player's **clock** (top right, with the controls), the **media line** (`4K · Dolby Vision · HEVC · TrueHD Atmos 7.1` after the episode line) and the **Magic Remote jitter gate** after BACK hides the controls, rebuilt on the new player controls.

## This fork's features

- **Magic Remote:** a hover never moves the page; a click opens what it clicks without scrolling to it; the top of Home glides evenly; every poster on screen takes the pointer.
- **Skip intros / Skip credits** (Settings > Playback) for every profile, not only one plex.tv grants the feature to.
- **Player:** a clock in the top-right corner while the controls are up; a media line after the episode line; Magic Remote jitter does not bring back controls hidden with BACK.

Not verified on a television yet: host unit tests and the ARM cross-build only.

## Installing

**Homebrew Channel (recommended, gets updates):** in Homebrew Channel open Settings, Repositories, and add

    https://raw.githubusercontent.com/danzig666/plx-native/homebrew/repo.json

then install **PlxNative** from that list. It replaces an installed PlxNative and keeps its sign-in. From this release on, fork builds are numbered `<major>.<minor>.<fork number>` (this one is **0.9.20**), so the Channel offers each new fork release as an update. A newer upstream release in webosbrew's own listing with a higher number (0.9.21 and up, or 0.10) will be offered as an update too, and would replace the fork.

**By hand:**

- `com.beb.plxnative_0.9.20_arm.ipk` installs **over** an existing PlxNative and keeps its sign-in.
- `com.beb.plxnative.debug_0.9.20_arm.ipk` installs **beside** it as a separate tile with its own sign-in (and a developer frame counter).

Install with webOS Dev Manager like any `.ipk`. Checksums are in `SHA256SUMS.txt`. The stable package reports no telemetry: no telemetry endpoint is built in.

The bundled FFmpeg is built by the same `ci/build-ffmpeg.sh` as upstream. Its LGPL corresponding source is the source asset on the [upstream v0.9.0 release](https://github.com/GLinnik21/plx-native/releases/tag/v0.9.0).
