# v0.9.0-fork.21 — upstream's new Settings, numbered 0.9.21
PlxNative from upstream's main branch as of 2026-11-06 (everything in [upstream v0.9.0](https://github.com/GLinnik21/plx-native/releases/tag/v0.9.0)) plus this fork's changes, built from [`claude/plx-native-version-diff-9faa0w`](https://github.com/danzig666/plx-native/tree/claude/plx-native-version-diff-9faa0w) by the fork's Sideload build workflow.

## New in this build

**Upstream main of 2026-11-06** merged in (17 changes since fork.20):

- **Settings are redesigned:** a new first page with grouped entries and a Diagnostics page, pages that slide in, and the posters' settings in their own section.
- **Playback:** when the Plex server retires a playback session, the app now tells it the session stopped, so that report no longer goes missing.
- **HUD gallery:** it accepts only a signed list of player-control packages, now served from huds.plxnative.com. The built-in look is named Built-in.
- A Catalan translation.

This fork's own changes are unchanged; Skip intros / Skip credits still show for every profile in the new Settings.

## From fork.20

- **Skip intros and Skip credits are in Settings > Playback for every profile.** Upstream shows them only when plex.tv says the profile's own account has the intro and credits marker features, which hid them here. A fix that counts a Plex Pass as granting both is proposed upstream ([#1246](https://github.com/GLinnik21/plx-native/pull/1246)).
- The events log says what plex.tv answered about those features (`marker grants:`).

## This fork's features

- **Magic Remote:** a hover never moves the page; a click opens what it clicks without scrolling to it; the top of Home glides evenly; every poster on screen takes the pointer.
- **Skip intros / Skip credits** (Settings > Playback) for every profile, not only one plex.tv grants the feature to.
- **Player:** a clock in the top-right corner while the controls are up; a media line after the episode line; Magic Remote jitter does not bring back controls hidden with BACK.

Not verified on a television yet: host unit tests and the ARM cross-build only.

## Installing

**Homebrew Channel (recommended, gets updates):** in Homebrew Channel open Settings, Repositories, and add

    https://raw.githubusercontent.com/danzig666/plx-native/homebrew/repo.json

then install **PlxNative** from that list. It replaces an installed PlxNative and keeps its sign-in. From this release on, fork builds are numbered `<major>.<minor>.<fork number>` (this one is **0.9.21**), so the Channel offers each new fork release as an update. A newer upstream release in webosbrew's own listing with a higher number (0.9.22 and up, or 0.10) will be offered as an update too, and would replace the fork.

**By hand:**

- `com.beb.plxnative_0.9.21_arm.ipk` installs **over** an existing PlxNative and keeps its sign-in.
- `com.beb.plxnative.debug_0.9.21_arm.ipk` installs **beside** it as a separate tile with its own sign-in (and a developer frame counter).

Install with webOS Dev Manager like any `.ipk`. Checksums are in `SHA256SUMS.txt`. The stable package reports no telemetry: no telemetry endpoint is built in.

The bundled FFmpeg is built by the same `ci/build-ffmpeg.sh` as upstream. Its LGPL corresponding source is the source asset on the [upstream v0.9.0 release](https://github.com/GLinnik21/plx-native/releases/tag/v0.9.0).
