# v0.9.0-fork.4 — Magic Remote pointer scrolling fixes, numbered 0.9.4
The same upstream base as fork.1 to fork.3 (upstream main of 2026-10-23, everything in [upstream v0.9.0](https://github.com/GLinnik21/plx-native/releases/tag/v0.9.0)) plus this fork's changes, built from [`claude/plx-native-version-diff-9faa0w`](https://github.com/danzig666/plx-native/tree/claude/plx-native-version-diff-9faa0w) by the fork's Sideload build workflow.

## New in this build

Fixes for the Magic Remote pointer after fork.3:

- **Home scrolls under the pointer again.** fork.3's edge glide held the pointer back from the cards at Home's top and bottom edges, so Home did not scroll at all. Home keeps its hover-to-scroll; the glide is only on the pages that scroll freely (libraries, Collections, the Watchlist, collections, people, Search and detail pages).
- **Pointing at a card no longer throws the list around.** Hovering a card used to pull its row up to the top of the screen, as the arrow keys do, so every hover moved the page up to a screenful, and a hover right after an edge glide undid it. Now a card that is already on screen moves nothing, and one cut off at the bottom scrolls the page just enough to show it. The arrow keys still place their row at the top.
- Edge gliding from fork.3 stays: rest the pointer near the top or bottom edge over empty space and the page glides.

## This fork's features

- **Skip intros** / **Skip credits**: *Show button* or *Skip automatically*, with an "Intro skipped" / "Credits skipped" notice; per profile.
- **BACK hides the controls** is now upstream's own; the fork adds two things on top: BACK still leaves while a video is loading, and Magic Remote jitter does not bring the hidden controls back.
- **Media line**, e.g. `4K · Dolby Vision · HEVC · TrueHD Atmos 7.1`.

Not verified on a television yet: host unit tests and the ARM cross-build only.

## Installing

**Homebrew Channel (recommended, gets updates):** in Homebrew Channel open Settings, Repositories, and add

    https://raw.githubusercontent.com/danzig666/plx-native/homebrew/repo.json

then install **PlxNative** from that list. It replaces an installed PlxNative and keeps its sign-in. From this release on, fork builds are numbered `<major>.<minor>.<fork number>` (this one is **0.9.4**), so the Channel offers each new fork release as an update. A newer upstream release in webosbrew's own listing with a higher number (0.9.5 and up, or 0.10) will be offered as an update too, and would replace the fork.

**By hand:**

- `com.beb.plxnative_0.9.4_arm.ipk` installs **over** an existing PlxNative and keeps its sign-in.
- `com.beb.plxnative.debug_0.9.4_arm.ipk` installs **beside** it as a separate tile with its own sign-in (and a developer frame counter).

Install with webOS Dev Manager like any `.ipk`. Checksums are in `SHA256SUMS.txt`. The stable package reports no telemetry: no telemetry endpoint is built in.

The bundled FFmpeg is built by the same `ci/build-ffmpeg.sh` as upstream. Its LGPL corresponding source is the source asset on the [upstream v0.9.0 release](https://github.com/GLinnik21/plx-native/releases/tag/v0.9.0).
