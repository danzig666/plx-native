# v0.10.0-fork.22 — upstream 0.10, numbered 0.10.22
PlxNative from upstream's main branch as of 2026-11-11 (upstream's 0.10.0, whose release notes have landed; its rc.1 is tagged) plus this fork's changes, built from [`claude/plx-native-version-diff-9faa0w`](https://github.com/danzig666/plx-native/tree/claude/plx-native-version-diff-9faa0w) by the fork's Sideload build workflow. Fork builds are now numbered on 0.10: this one is **0.10.22**, so it stays ahead of upstream's 0.10.0 in Homebrew Channel.

## New in this build

**Upstream main of 2026-11-11** merged in (61 changes since fork.21), among them:

- **Playback:** a seek that never reaches the picture is recovered; a seek that reloads keeps its target on the clock until the first frame; an HTTP/2 seek opens a fresh connection; retranscodes recover; the default version is one the TV can decode; HLS and Dolby Vision resume fixes; the app honours a Plex server stopping playback.
- **The player HUD can show an estimated finish time** beside the remaining time.
- **Home:** the big top banner shows playback progress and the movie's or show's details; Continue Watching is a row of stills.
- **Libraries** remember the pages you had open; Grid BACK and UP fixes; polish on Detail, Library and Settings.
- **Magic Remote after BACK** (upstream's own fix): the pointer hides and a hand's small motion no longer brings the controls back.
- **Skip intros / Skip credits** appear for a Plex Pass account (this fork's [#1246](https://github.com/GLinnik21/plx-native/pull/1246), merged upstream).
- Settings > Video & playback > Playback engine: a per-profile opt-in to an experimental engine.

This fork's own changes on top:

- Dropped, because upstream now does them: the fork's Magic Remote jitter gate after BACK, and showing Skip intros / Skip credits for every profile (they now show when plex.tv reports a Plex Pass, intro or credits feature for the profile).
- Kept: the **clock** in the top-right corner while the controls are up (now on upstream's wall clock), the **media line** after the episode line, and the Magic Remote scrolling and hover changes.

## This fork's features

- **Magic Remote:** a hover never moves the page; a click opens what it clicks without scrolling to it; the top of Home glides evenly; every poster on screen takes the pointer.
- **Player:** a clock (the current time) in the top-right corner while the controls are up; a media line (`4K · Dolby Vision · HEVC · TrueHD Atmos 7.1`) after the episode line.

Not verified on a television yet: host unit tests and the ARM cross-build only.

## Installing

**Homebrew Channel (recommended, gets updates):** in Homebrew Channel open Settings, Repositories, and add

    https://raw.githubusercontent.com/danzig666/plx-native/homebrew/repo.json

then install **PlxNative** from that list. It replaces an installed PlxNative and keeps its sign-in. From this release on, fork builds are numbered `<major>.<minor>.<fork number>` (this one is **0.10.22**), so the Channel offers each new fork release as an update. A newer upstream release in webosbrew's own listing with a higher number (0.10.23 and up, or 0.11) will be offered as an update too, and would replace the fork.

**By hand:**

- `com.beb.plxnative_0.10.22_arm.ipk` installs **over** an existing PlxNative and keeps its sign-in.
- `com.beb.plxnative.debug_0.10.22_arm.ipk` installs **beside** it as a separate tile with its own sign-in (and a developer frame counter).

Install with webOS Dev Manager like any `.ipk`. Checksums are in `SHA256SUMS.txt`. The stable package reports no telemetry: no telemetry endpoint is built in.

The bundled FFmpeg is built by the same `ci/build-ffmpeg.sh` as upstream. Its LGPL corresponding source is the source asset on the [upstream v0.9.0 release](https://github.com/GLinnik21/plx-native/releases/tag/v0.9.0).
