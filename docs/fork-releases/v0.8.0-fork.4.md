# v0.8.0-fork.4 — upstream main of 2026-10-18, and Hungarian
PlxNative from upstream's **main branch as of 2026-10-18** (unreleased work after v0.8.0) plus this fork's changes, built from [`claude/plx-native-version-diff-9faa0w`](https://github.com/danzig666/plx-native/tree/claude/plx-native-version-diff-9faa0w) by the fork's Sideload build workflow. It still reports version 0.8.0.

## New in this build

- **Magyar (Hungarian)** UI language, reviewed by a native speaker: Settings → Language → Magyar (applies at the next launch). The fork's own settings and notices are translated too.
- From upstream since fork.3 (not yet in an upstream release):
  - **Faster seeking on webOS 5 and later** (the C-series included): a seek moves in place through LG's own Seek instead of reloading the stream.
  - **Preview pictures while scrubbing**, and click-to-confirm: ←/→ move the target, OK jumps there, BACK cancels.
  - **Watchlist** tab (plex.tv Watchlist), with Add/Remove on detail pages and hold menus.
  - **HDR overlay brightness** (Settings → Playback): the controls and subtitles are dimmed on an HDR or Dolby Vision picture, 75% by default.
  - **Subtitles drawn through libass**, a **Huge** caption size, and correct decoding of older CJK subtitle encodings.
  - German, Italian and Portuguese; emoji in titles; Home and pages refresh when your server reports changes; a screensaver that takes the decoder pauses playback instead of breaking it; a remux tells the TV the real frame rate.

## This fork's features

- **Skip intros** / **Skip credits**: *Show button* or *Skip automatically*, with an "Intro skipped" / "Credits skipped" notice; per profile.
- **BACK hides the controls** is now upstream's own; the fork adds two things on top: BACK still leaves while a video is loading, and Magic Remote jitter does not bring the hidden controls back.
- **Media line**, e.g. `4K · Dolby Vision · HEVC · TrueHD Atmos 7.1`.
- **Removed:** the fork's "controls follow the subtitle colour" dimming. Upstream's **HDR overlay brightness** setting replaces it (both together would dim twice).

Not verified on a television yet: host unit tests and the ARM cross-build only.

## Installing

- `com.beb.plxnative_0.8.0_arm.ipk` installs **over** an existing PlxNative and keeps its sign-in. A later Homebrew Channel update to a newer upstream version will replace it.
- `com.beb.plxnative.debug_0.8.0_arm.ipk` installs **beside** it as a separate tile with its own sign-in (and a developer frame counter).

Install with webOS Dev Manager like any `.ipk`. Checksums are in `SHA256SUMS.txt`. The stable package reports no telemetry: no telemetry endpoint is built in.

The bundled FFmpeg is built by the same `ci/build-ffmpeg.sh` as upstream. Its LGPL corresponding source is the source asset on the [upstream v0.8.0 release](https://github.com/GLinnik21/plx-native/releases/tag/v0.8.0).
