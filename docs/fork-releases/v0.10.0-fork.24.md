# v0.10.0-fork.24 — upstream after 0.10.1, numbered 0.10.24
PlxNative from upstream's main branch as of 2026-11-19 (everything in [upstream v0.10.1](https://github.com/plxnative/plx-native/releases/tag/v0.10.1)) plus this fork's changes, built from [`claude/plx-native-version-diff-9faa0w`](https://github.com/danzig666/plx-native/tree/claude/plx-native-version-diff-9faa0w) by the fork's Sideload build workflow.

## New in this build

**Upstream main of 2026-11-19** merged in (57 changes since fork.23; upstream released 0.10.1 meanwhile):

- **Playback:** a direct-play stream that runs short pauses and shows Buffering instead of playing in slow motion; Play pressed while a held start waits now resumes; seek and image-subtitle fixes; a Dolby Vision picture-area fix.
- **Versions:** Play Version and Also available work again; choosing a version judges Dolby Vision and bitrate as direct play does; Detail's info row, its badge and the Home banner name the version Play starts, with HDR or Dolby Vision beside the resolution.
- **Home:** Continue Watching no longer hides its newest cards when a second server answers late; focus stays in its row when its remembered place expires; posters with long art paths load.
- **Menus:** glass menus are frosted and open and close like iOS 26.
- Typed text reaches every text field; first-run setup follows the Settings design; IPv6 is preferred with a quick IPv4 fallback; the experimental playback engine is allowed on webOS 25.
- Eleven fixes from an audit of the app's internal state handling.

This fork's own changes are unchanged.

## This fork's features

- **Magic Remote:** a hover never moves the page; a click opens what it clicks without scrolling to it; the top of Home glides evenly; every poster on screen takes the pointer.
- **Player:** a clock (the current time) in the top-right corner while the controls are up; a media line (`4K · Dolby Vision · HEVC · TrueHD Atmos 7.1`) after the episode line.

Not verified on a television yet: host unit tests and the ARM cross-build only.

## Installing

**Homebrew Channel (recommended, gets updates):** in Homebrew Channel open Settings, Repositories, and add

    https://raw.githubusercontent.com/danzig666/plx-native/homebrew/repo.json

then install **PlxNative** from that list. It replaces an installed PlxNative and keeps its sign-in. From this release on, fork builds are numbered `<major>.<minor>.<fork number>` (this one is **0.10.24**), so the Channel offers each new fork release as an update. A newer upstream release in webosbrew's own listing with a higher number (0.10.25 and up, or 0.11) will be offered as an update too, and would replace the fork.

**By hand:**

- `com.beb.plxnative_0.10.24_arm.ipk` installs **over** an existing PlxNative and keeps its sign-in.
- `com.beb.plxnative.debug_0.10.24_arm.ipk` installs **beside** it as a separate tile with its own sign-in (and a developer frame counter).

Install with webOS Dev Manager like any `.ipk`. Checksums are in `SHA256SUMS.txt`. The stable package reports no telemetry: no telemetry endpoint is built in.

The bundled FFmpeg is built by the same `ci/build-ffmpeg.sh` as upstream. Its LGPL corresponding source is the source asset on the [upstream v0.10.1 release](https://github.com/plxnative/plx-native/releases/tag/v0.10.1).
