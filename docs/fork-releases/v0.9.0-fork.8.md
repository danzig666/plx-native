# v0.9.0-fork.8 — edge scrolling pauses on the top bar, numbered 0.9.8
The same upstream base as fork.1 to fork.7 (upstream main of 2026-10-23, everything in [upstream v0.9.0](https://github.com/GLinnik21/plx-native/releases/tag/v0.9.0)) plus this fork's changes, built from [`claude/plx-native-version-diff-9faa0w`](https://github.com/danzig666/plx-native/tree/claude/plx-native-version-diff-9faa0w) by the fork's Sideload build workflow.

## New in this build

- **The edge scrolling stops on the top bar's buttons.** With the pointer on the profile button or on Home / Movies / Watchlist / Search the page no longer glides; move off them (still near the edge) and it glides on.
- From fork.7: **the posters peeking at the bottom of Home are clickable.** On the top of Home the first shelf shows under the big picture; clicking one of its posters now scrolls the page down to it (a second click opens it). The same goes for a poster cut off by the bottom edge further down. This was upstream behaviour (nothing there could be clicked until you scrolled).
- The Magic Remote pointer scrolling from fork.6:

- **Rest the pointer near the top or bottom edge and the page glides smoothly**, on Home and on the movie lists alike, whether the pointer is over a card or not. It eases in after a moment and moves faster the closer the pointer is to the edge. On Home it slides from the big hero picture into the shelves and back. Over the navigation bar at the top the pointer works the bar as usual.
- **Pointing at a card no longer moves the page.** It only highlights the card; partly shown cards stay where they are.
- **Clicking a card opens it, as before**; on Home a card only partly on screen is scrolled into view by the first click.
- **The arrow keys move a whole row at a time**, as before.

Applies to Home, libraries, Collections, the Watchlist, collections, people, Search and detail pages.

## This fork's features

- **Skip intros** / **Skip credits**: *Show button* or *Skip automatically*, with an "Intro skipped" / "Credits skipped" notice; per profile.
- **BACK hides the controls** is now upstream's own; the fork adds two things on top: BACK still leaves while a video is loading, and Magic Remote jitter does not bring the hidden controls back.
- **Media line**, e.g. `4K · Dolby Vision · HEVC · TrueHD Atmos 7.1`.

Not verified on a television yet: host unit tests and the ARM cross-build only.

## Installing

**Homebrew Channel (recommended, gets updates):** in Homebrew Channel open Settings, Repositories, and add

    https://raw.githubusercontent.com/danzig666/plx-native/homebrew/repo.json

then install **PlxNative** from that list. It replaces an installed PlxNative and keeps its sign-in. From this release on, fork builds are numbered `<major>.<minor>.<fork number>` (this one is **0.9.8**), so the Channel offers each new fork release as an update. A newer upstream release in webosbrew's own listing with a higher number (0.9.9 and up, or 0.10) will be offered as an update too, and would replace the fork.

**By hand:**

- `com.beb.plxnative_0.9.8_arm.ipk` installs **over** an existing PlxNative and keeps its sign-in.
- `com.beb.plxnative.debug_0.9.8_arm.ipk` installs **beside** it as a separate tile with its own sign-in (and a developer frame counter).

Install with webOS Dev Manager like any `.ipk`. Checksums are in `SHA256SUMS.txt`. The stable package reports no telemetry: no telemetry endpoint is built in.

The bundled FFmpeg is built by the same `ci/build-ffmpeg.sh` as upstream. Its LGPL corresponding source is the source asset on the [upstream v0.9.0 release](https://github.com/GLinnik21/plx-native/releases/tag/v0.9.0).
