# v0.10.0-fork.25 — PlxNative updates itself, numbered 0.10.25
PlxNative from upstream's main branch as of 2026-11-19 (everything in [upstream v0.10.1](https://github.com/plxnative/plx-native/releases/tag/v0.10.1)) plus this fork's changes, built from [`claude/plx-native-version-diff-9faa0w`](https://github.com/danzig666/plx-native/tree/claude/plx-native-version-diff-9faa0w) by the fork's Sideload build workflow.

## New in this build

- **Settings › Software update.** PlxNative checks this fork's releases when it starts (at most once every 20 hours) and when you choose **Check for updates**. When a newer version exists, the TV says so once, the Settings row shows "0.10.26 available", and **Install 0.10.26** hands it to Homebrew Channel, which downloads it, checks it and installs it while the page shows the progress. PlxNative closes while the update installs; open it again afterwards. Homebrew Channel is needed, as it is to install the fork at all. The debug tile (com.beb.plxnative.debug) is a separate app and does not update itself.
- This is the first build with the updater, so it can only report that it is up to date; the next fork release is the first one it can install.

## From fork.24

**Upstream main of 2026-11-19** merged in (57 changes since fork.23; upstream released 0.10.1 meanwhile): a direct-play stream that runs short pauses and shows Buffering instead of playing in slow motion; Play Version and Also available work again; Detail and the Home banner name HDR or Dolby Vision beside the resolution; Continue Watching no longer hides its newest cards; frosted glass menus; typed text reaches every text field; IPv6 with a quick IPv4 fallback; eleven fixes from an audit of the app's internal state handling.

## This fork's features

- **Magic Remote:** a hover never moves the page; a click opens what it clicks without scrolling to it; the top of Home glides evenly; every poster on screen takes the pointer.
- **Software update** in Settings: checks this fork's releases and installs a newer one through Homebrew Channel.
- **Player:** a clock (the current time) in the top-right corner while the controls are up; a media line (`4K · Dolby Vision · HEVC · TrueHD Atmos 7.1`) after the episode line.

Not verified on a television yet: host unit tests and the ARM cross-build only.

## Installing

**Homebrew Channel (recommended, gets updates):** in Homebrew Channel open Settings, Repositories, and add

    https://raw.githubusercontent.com/danzig666/plx-native/homebrew/repo.json

then install **PlxNative** from that list. It replaces an installed PlxNative and keeps its sign-in. From this release on, fork builds are numbered `<major>.<minor>.<fork number>` (this one is **0.10.25**), so the Channel offers each new fork release as an update. A newer upstream release in webosbrew's own listing with a higher number (0.10.26 and up, or 0.11) will be offered as an update too, and would replace the fork.

**By hand:**

- `com.beb.plxnative_0.10.25_arm.ipk` installs **over** an existing PlxNative and keeps its sign-in.
- `com.beb.plxnative.debug_0.10.25_arm.ipk` installs **beside** it as a separate tile with its own sign-in (and a developer frame counter).

Install with webOS Dev Manager like any `.ipk`. Checksums are in `SHA256SUMS.txt`. The stable package reports no telemetry: no telemetry endpoint is built in.

The bundled FFmpeg is built by the same `ci/build-ffmpeg.sh` as upstream. Its LGPL corresponding source is the source asset on the [upstream v0.10.1 release](https://github.com/plxnative/plx-native/releases/tag/v0.10.1).
