# v0.7.0-fork.1 — v0.7.0 with this fork's player extras
PlxNative **v0.7.0** plus this fork's remaining changes, built from [`claude/plx-native-version-diff-9faa0w`](https://github.com/danzig666/plx-native/tree/claude/plx-native-version-diff-9faa0w) by the fork's Sideload build workflow on the project's own toolchain.

## New since v0.6.6-fork.4

**Everything in upstream v0.7.0**: trailer mode on the detail page, the redesigned person page, a Plays sort in the library, the account's preferred audio language, image subtitles in compressed MKV tracks, Dolby Vision declared only when the TV supports it, sturdier profiles and storage, and more. See the [upstream v0.7.0 release](https://github.com/GLinnik21/plx-native/releases/tag/v0.7.0).

Five of this fork's changes were accepted upstream and are now part of v0.7.0 itself: subtitle color, external subtitles, cover-art retry, the seek bar fixes, and honouring a show's audio and subtitle language settings.

The rest of this fork, ported onto v0.7.0:

- **Skip intros automatically**: a switch under Settings → **Playback** (off by default). When it is on, the app jumps past a show's intro as soon as it starts instead of showing the Skip Intro button, and an **"Intro skipped"** notice appears at the top of the screen for a couple of seconds.
- **Skip credits automatically**: a second switch beside it (off by default). Credits in the middle of an item are skipped with a **"Credits skipped"** notice. At the closing credits the next episode starts straight away, as if you pressed Next Episode; with nothing queued, the item finishes as if you pressed Skip Credits.
- **BACK with the controls showing hides them**; BACK again leaves playback. While a video is still loading, BACK leaves straight away.
- **Magic Remote jitter no longer brings the controls back** after BACK hid them. The pointer has to move clearly (about 120 px) before they reappear.
- **Player controls follow the subtitle color**, one step brighter than the caption, so on an HDR picture the whole overlay is dimmed together. White and Silver leave the controls at full brightness.
- **Media line**: next to the line above the title, e.g. `4K · Dolby Vision · HEVC · TrueHD Atmos 7.1`, `1080p · H.264 · DD+ 5.1`, or `Converting · H.264 · AAC` on a transcode.

Not verified on a television yet: host unit tests and the ARM cross-build only.

## Installing

- `com.beb.plxnative_0.7.0_arm.ipk` installs **over** an existing PlxNative and keeps its sign-in. A later Homebrew Channel update to a newer upstream version will replace it.
- `com.beb.plxnative.debug_0.7.0_arm.ipk` installs **beside** it as a separate tile with its own sign-in (and a developer frame counter).

Install with webOS Dev Manager like any `.ipk`. Checksums are in `SHA256SUMS.txt`. The stable package reports no telemetry: no telemetry endpoint is built in.

The bundled FFmpeg is built by the same `ci/build-ffmpeg.sh` as upstream v0.7.0. Its LGPL corresponding source is the source asset on the [upstream v0.7.0 release](https://github.com/GLinnik21/plx-native/releases/tag/v0.7.0).
