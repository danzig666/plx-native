# v0.8.0-fork.5 — upstream main of 2026-10-21
PlxNative from upstream's **main branch as of 2026-10-21** (unreleased work after v0.8.0) plus this fork's changes, built from [`claude/plx-native-version-diff-9faa0w`](https://github.com/danzig666/plx-native/tree/claude/plx-native-version-diff-9faa0w) by the fork's Sideload build workflow. It still reports version 0.8.0.

## New in this build

From upstream since fork.4 (not yet in an upstream release):

- **Dolby Vision Profile 7 direct-plays** (UHD Blu-ray remuxes), converted to Profile 8.1 in the app; Dolby Vision is kept when the server copies the video, and declared on AV1 too.
- **HDR10+ HEVC files** play: the HDR10+ metadata is stripped where it would trip the pipeline.
- A file whose **audio is stored far ahead of its video** starts and keeps playing; a direct-play stream that ends early, stalls or goes silent recovers.
- **Continue Watching** shows one tile per show across servers, like the official client.
- **Smoother browsing**: Home and Library no longer drop a frame on a key press, and holding a key over posters went from 52 to 59 fps on the TV.
- **Library Collections** redesign with Collections and Recommended pages, and an **Under posters** setting for what shows under the focused poster.
- Detail keeps the show logo when you choose an episode; Down from the hero goes to the first row.
- **Hungarian is now part of upstream** (#835); this build carries the same catalog plus the fork's own strings.

## This fork's features

- **Skip intros** / **Skip credits**: *Show button* or *Skip automatically*, with an "Intro skipped" / "Credits skipped" notice; per profile.
- **BACK hides the controls** is now upstream's own; the fork adds two things on top: BACK still leaves while a video is loading, and Magic Remote jitter does not bring the hidden controls back.
- **Media line**, e.g. `4K · Dolby Vision · HEVC · TrueHD Atmos 7.1`.

Not verified on a television yet: host unit tests and the ARM cross-build only.

## Installing

- `com.beb.plxnative_0.8.0_arm.ipk` installs **over** an existing PlxNative and keeps its sign-in. A later Homebrew Channel update to a newer upstream version will replace it.
- `com.beb.plxnative.debug_0.8.0_arm.ipk` installs **beside** it as a separate tile with its own sign-in (and a developer frame counter).

Install with webOS Dev Manager like any `.ipk`. Checksums are in `SHA256SUMS.txt`. The stable package reports no telemetry: no telemetry endpoint is built in.

The bundled FFmpeg is built by the same `ci/build-ffmpeg.sh` as upstream. Its LGPL corresponding source is the source asset on the [upstream v0.8.0 release](https://github.com/GLinnik21/plx-native/releases/tag/v0.8.0).
