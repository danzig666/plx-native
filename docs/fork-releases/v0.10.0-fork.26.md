# v0.10.0-fork.26 — Live TV, numbered 0.10.26
PlxNative from upstream's main branch as of 2026-11-25 (everything in [upstream v0.10.1](https://github.com/plxnative/plx-native/releases/tag/v0.10.1)) plus this fork's changes, built from [`claude/plx-native-version-diff-9faa0w`](https://github.com/danzig666/plx-native/tree/claude/plx-native-version-diff-9faa0w) by the fork's Sideload build workflow.

## New in this build

**Upstream main of 2026-11-25** merged in (66 changes since fork.25), among them:

- **Live TV:** watch your Plex server's live channels, with a TV tab of channel covers; each airing says its time and how long is left ("21:00–22:00 · 22m left").
- **Playback:** Dolby Vision is recognised from the stream itself when the file does not say so; stopping a play that never started frees the server's transcoder at once; background reads no longer make the server refresh an item first.
- **The experimental playback engine** is also offered on webOS 23 (an LG C3).
- A Watchlist action on filmography credits; posters name Dolby Vision; a warning to server owners about affected Plex Media Server builds; a Croatian translation; Detail and item-menu focus fixes.
- Upstream reorganised the app into platforms (webOS, the desktop simulators and a Samsung Tizen port); nothing changes on the TV.

This fork's own changes are unchanged: the top-right clock now reads the same per-frame time as Live TV.

**This is the first release Settings › Software update can install.** On fork.25, open Settings › Software update, choose Check for updates, then Install 0.10.26.

## From fork.25

- **Settings › Software update.** PlxNative checks this fork's releases when it starts (at most once every 20 hours) and when you choose **Check for updates**. When a newer version exists, the TV says so once, the Settings row names it, and **Install** hands it to Homebrew Channel, which downloads, checks and installs it while the page shows the progress. PlxNative closes while the update installs. The debug tile does not update itself.

## This fork's features

- **Magic Remote:** a hover never moves the page; a click opens what it clicks without scrolling to it; the top of Home glides evenly; every poster on screen takes the pointer.
- **Software update** in Settings: checks this fork's releases and installs a newer one through Homebrew Channel.
- **Player:** a clock (the current time) in the top-right corner while the controls are up; a media line (`4K · Dolby Vision · HEVC · TrueHD Atmos 7.1`) after the episode line.

Not verified on a television yet: host unit tests and the ARM cross-build only.

## Installing

**Homebrew Channel (recommended, gets updates):** in Homebrew Channel open Settings, Repositories, and add

    https://raw.githubusercontent.com/danzig666/plx-native/homebrew/repo.json

then install **PlxNative** from that list. It replaces an installed PlxNative and keeps its sign-in. From this release on, fork builds are numbered `<major>.<minor>.<fork number>` (this one is **0.10.26**), so the Channel offers each new fork release as an update. A newer upstream release in webosbrew's own listing with a higher number (0.10.27 and up, or 0.11) will be offered as an update too, and would replace the fork.

**By hand:**

- `com.beb.plxnative_0.10.26_arm.ipk` installs **over** an existing PlxNative and keeps its sign-in.
- `com.beb.plxnative.debug_0.10.26_arm.ipk` installs **beside** it as a separate tile with its own sign-in (and a developer frame counter).

Install with webOS Dev Manager like any `.ipk`. Checksums are in `SHA256SUMS.txt`. The stable package reports no telemetry: no telemetry endpoint is built in.

The bundled FFmpeg is built by the same `ci/build-ffmpeg.sh` as upstream. Its LGPL corresponding source is the source asset on the [upstream v0.10.1 release](https://github.com/plxnative/plx-native/releases/tag/v0.10.1).
