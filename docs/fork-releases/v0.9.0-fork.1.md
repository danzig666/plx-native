# v0.9.0-fork.1 — upstream 0.9.0, numbered 0.9.1
PlxNative from upstream's **main branch as of 2026-10-23**, which contains everything in the [upstream v0.9.0 release](https://github.com/GLinnik21/plx-native/releases/tag/v0.9.0) and a few fixes after it, plus this fork's changes, built from [`claude/plx-native-version-diff-9faa0w`](https://github.com/danzig666/plx-native/tree/claude/plx-native-version-diff-9faa0w) by the fork's Sideload build workflow.

## New in this build

**Numbered 0.9.1, so the Homebrew Channel keeps offering the fork:** upstream's 0.9.0 is now in webosbrew's own listing, and anything below 0.9.1 would have been offered upstream's 0.9.0 as an update (which replaces the fork).

From upstream since fork.5 (see the [v0.9.0 release notes](https://github.com/GLinnik21/plx-native/releases/tag/v0.9.0) for everything since 0.8.0):

- **Launch links**: another app on the TV (a launcher's Continue Watching row, say) can open a title's page in PlxNative or start it playing.
- A film **ends on the pipeline's end-of-stream**, so it no longer stays on its last frame when the audio runs past the picture.
- **DTS** from a real Plex server direct-plays on sets whose codec table lists DTS; Force Direct Play names the audio codec it refuses.
- **Continue Watching** captions read like *S3 · E4 · 18m left*.
- The player **shortens a long title** and reveals it while paused.
- *Also available* no longer shows a wrong runtime on show and season pages; two Auto-quality recovery fixes.
- Opt-in reporting carries more (freezes, crash-free sessions, per-screen smoothness classes), only if Crash reports or Product analytics is on.

## This fork's features

- **Skip intros** / **Skip credits**: *Show button* or *Skip automatically*, with an "Intro skipped" / "Credits skipped" notice; per profile.
- **BACK hides the controls** is now upstream's own; the fork adds two things on top: BACK still leaves while a video is loading, and Magic Remote jitter does not bring the hidden controls back.
- **Media line**, e.g. `4K · Dolby Vision · HEVC · TrueHD Atmos 7.1`.

Not verified on a television yet: host unit tests and the ARM cross-build only.

## Installing

**Homebrew Channel (recommended, gets updates):** in Homebrew Channel open Settings, Repositories, and add

    https://raw.githubusercontent.com/danzig666/plx-native/homebrew/repo.json

then install **PlxNative** from that list. It replaces an installed PlxNative and keeps its sign-in. From this release on, fork builds are numbered `<major>.<minor>.<fork number>` (this one is **0.9.1**), so the Channel offers each new fork release as an update. A newer upstream release in webosbrew's own listing with a higher number (0.9.2 and up, or 0.10) will be offered as an update too, and would replace the fork.

**By hand:**

- `com.beb.plxnative_0.9.1_arm.ipk` installs **over** an existing PlxNative and keeps its sign-in.
- `com.beb.plxnative.debug_0.9.1_arm.ipk` installs **beside** it as a separate tile with its own sign-in (and a developer frame counter).

Install with webOS Dev Manager like any `.ipk`. Checksums are in `SHA256SUMS.txt`. The stable package reports no telemetry: no telemetry endpoint is built in.

The bundled FFmpeg is built by the same `ci/build-ffmpeg.sh` as upstream. Its LGPL corresponding source is the source asset on the [upstream v0.9.0 release](https://github.com/GLinnik21/plx-native/releases/tag/v0.9.0).
