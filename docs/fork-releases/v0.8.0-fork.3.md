# v0.8.0-fork.3 — this fork on upstream's current main
PlxNative from upstream's **main branch as of 2026-10-14** (unreleased work after v0.8.0) plus this fork's changes, built from [`claude/plx-native-version-diff-9faa0w`](https://github.com/danzig666/plx-native/tree/claude/plx-native-version-diff-9faa0w) by the fork's Sideload build workflow on the project's own toolchain. It still reports version 0.8.0.

## New from upstream since v0.8.0-fork.2

Not yet in an upstream release; see upstream's [main branch](https://github.com/GLinnik21/plx-native/commits/main) for the full list.

- **Track memory**: an audio or subtitle pick on an episode is remembered for its show, carried to the next episode (an external subtitle in the same language too, and *Forced only*), and written back to Plex.
- **Per-profile settings**: the player settings are kept per Plex profile; Settings names whose settings it shows. Hero trailer autoplay is per profile too.
- **Holding ←/→ seeks faster and faster**, in doubling steps up to 320×.
- **French** UI language.
- **VP9 direct play** on sets whose decoder list includes it (10-bit on the webOS 4 family), HDR10 VP9 announced as HDR; formats the pipeline cannot take are refused up front.
- **Subtitles** wrap by pixel width (at most 75% of the screen), are no longer cut off after three lines, and more styled ASS files load.
- **Show pages open at the resume point**; Continue Watching opens the show.
- A direct-play transfer the server cuts mid-film reconnects; a film whose audio starts late plays from the start (the fix from this fork, as upstream hardened it).
- Lists page to their real end, rows show placeholder cards while more loads, Library posters load ahead of the scroll.
- Clearer crash and playback-error reports.

## This fork's features, carried over

- **Skip intros** and **Skip credits** (Settings → Playback): *Show button* (default) or *Skip automatically*, with an "Intro skipped" / "Credits skipped" notice. Like upstream's other player settings they are now **per profile**: each profile picks its own, and a profile that has not picked yet keeps what you set in fork.1/fork.2.
- **BACK with the controls showing hides them**; BACK again leaves. Magic Remote jitter no longer brings them back.
- **Player controls follow the subtitle colour**, one step brighter than the caption.
- **Media line**, e.g. `1080p · H.264 · DD+ 5.1`.
- French strings for the fork's settings and notices.

Not verified on a television yet: host unit tests and the ARM cross-build only.

## Installing

- `com.beb.plxnative_0.8.0_arm.ipk` installs **over** an existing PlxNative and keeps its sign-in. A later Homebrew Channel update to a newer upstream version will replace it.
- `com.beb.plxnative.debug_0.8.0_arm.ipk` installs **beside** it as a separate tile with its own sign-in (and a developer frame counter).

Install with webOS Dev Manager like any `.ipk`. Checksums are in `SHA256SUMS.txt`. The stable package reports no telemetry: no telemetry endpoint is built in.

The bundled FFmpeg is built by the same `ci/build-ffmpeg.sh` as upstream. Its LGPL corresponding source is the source asset on the [upstream v0.8.0 release](https://github.com/GLinnik21/plx-native/releases/tag/v0.8.0).
