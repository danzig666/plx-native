# v0.10.0-fork.23 — upstream 0.10.0 as released, numbered 0.10.23
PlxNative from upstream's main branch as of 2026-11-14 (everything in [upstream v0.10.0](https://github.com/GLinnik21/plx-native/releases/tag/v0.10.0)) plus this fork's changes, built from [`claude/plx-native-version-diff-9faa0w`](https://github.com/danzig666/plx-native/tree/claude/plx-native-version-diff-9faa0w) by the fork's Sideload build workflow.

## New in this build

**Upstream main of 2026-11-14** merged in (46 changes since fork.22, upstream's 0.10.0 release among them):

- **Subtitles:** a Yellow subtitle colour (Settings, beside Size and Position), for SRT and ASS tracks too; ASS subtitles use the fonts the file carries and show karaoke on the TV.
- **Player:** Previous always plays the previous episode, also right after a fresh play; timed skip prompts follow the countdown; nine fixes from upstream's first release candidate (Home banner, Settings, player controls, Library restore).
- **Playback:** audio is fed, not dropped, while the video side is backed up; network fixes for cancelling a stream and probing its speed.
- **Trailer previews** stop cleanly and say why one was refused.

This fork's own changes are unchanged.

## This fork's features

- **Magic Remote:** a hover never moves the page; a click opens what it clicks without scrolling to it; the top of Home glides evenly; every poster on screen takes the pointer.
- **Player:** a clock (the current time) in the top-right corner while the controls are up; a media line (`4K · Dolby Vision · HEVC · TrueHD Atmos 7.1`) after the episode line.

Not verified on a television yet: host unit tests and the ARM cross-build only.

## Installing

**Homebrew Channel (recommended, gets updates):** in Homebrew Channel open Settings, Repositories, and add

    https://raw.githubusercontent.com/danzig666/plx-native/homebrew/repo.json

then install **PlxNative** from that list. It replaces an installed PlxNative and keeps its sign-in. From this release on, fork builds are numbered `<major>.<minor>.<fork number>` (this one is **0.10.23**), so the Channel offers each new fork release as an update. A newer upstream release in webosbrew's own listing with a higher number (0.10.24 and up, or 0.11) will be offered as an update too, and would replace the fork.

**By hand:**

- `com.beb.plxnative_0.10.23_arm.ipk` installs **over** an existing PlxNative and keeps its sign-in.
- `com.beb.plxnative.debug_0.10.23_arm.ipk` installs **beside** it as a separate tile with its own sign-in (and a developer frame counter).

Install with webOS Dev Manager like any `.ipk`. Checksums are in `SHA256SUMS.txt`. The stable package reports no telemetry: no telemetry endpoint is built in.

The bundled FFmpeg is built by the same `ci/build-ffmpeg.sh` as upstream. Its LGPL corresponding source is the source asset on the [upstream v0.10.0 release](https://github.com/GLinnik21/plx-native/releases/tag/v0.10.0).
